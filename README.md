# Bandana WagePage

Wage transparency platform by Bandana. Upload, browse, and compare public payroll data across employers and states.

## Features

- Upload payroll CSVs or PDFs — auto-parses any format (NYC, LA, etc.)
- Browse wages by employer, role, and state
- Percentile explorer — see pay at any percentile
- Career ladder builder — link promotional paths and see pay progression
- "A Word From Benji" — AI-generated insights for every role
- Download source data as CSV

## Built With

- React + Vite
- Recharts for data visualization
- Claude API for PDF parsing
